# REVOLT 2150: SQUAD ALLIANCE
**Built with Godot Engine 4.7 (Native 3D / Vulkan & Metal Pipeline)**

An industrial cyberpunk 3D mech combat game inspired by *RoboCop: Rogue City* and classic bipedal battle walkers.

---

## ⚡ Quick Launch

### 1. Launch Game Immediately
From your terminal:
```bash
cd /Users/akash/GAMEATHON/revolt_godot
./run_game.sh
```
Or directly with Godot CLI:
```bash
godot --path /Users/akash/GAMEATHON/revolt_godot
```

### 2. Open in Godot Editor
```bash
./edit_game.sh
```
Or open `/Applications/Godot.app` and choose `/Users/akash/GAMEATHON/revolt_godot`.

## 🎮 Controls

| Action | Input | Description |
| :--- | :--- | :--- |
| **Move Walker** | `W` `A` `S` `D` | Heavy hydraulic bipedal locomotive control |
| **Aim Turret / Cockpit** | `Mouse` | Over-the-shoulder 3D targeting reticle |
| **Dual Heavy Autocannons**| `Left Click` | Alternating left/right heavy tracer salvos with barrel recoil |
| **EMP Shockwave Blast** | `Q` or `Right Click` | 14m radius electromagnetic pulse that stuns rogue mechs for 6.5s |
| **Reprogram Alliance** | Hold `E` (near stunned bot) | Hack malfunctioning robots to convert them into loyal combat allies |
| **Rocket Thruster Dash** | `Spacebar` | Quick evasive repositioning dodge |
| **Release / Recapture Mouse** | `ESC` | Toggle cursor for window management |

## 📖 Storyline & Objective
- **The Setting:** 22nd Century robotics complex created by Dr. Sterling.
- **The Anomaly:** Flagship titan **OMEGA-ZERO** malfunctions and broadcasts a rogue purge code to all factory and patrol robots.
- **The Resistance:** Teen hero **KAI** pilots an experimental Vanguard Walker, supported remotely by tactical hacker **MAYA** and heavy munitions specialist **JAX**.
- **The Alliance Mechanic:** Use your EMP cannon to disrupt enemy logic subroutines. Approach stunned units and hold `E` to convert them into Allied Squad Mechs that flank and protect you!
- **Climax:** Survive Wave 1 (Patrol Grunts) and Wave 2 (Heavy Bruisers) to face **OMEGA-ZERO** in the final boxing ring arena showdown!
