# 🚀 Template 3: Phaser 3 + Vite

A full, modern JavaScript game boilerplate using the world's most popular 2D HTML5 game engine (Phaser 3) bundled with Vite.

## Key Features:
- **Pre-installed Dependencies**: `node_modules` is already installed and cached.
- **Arcade Physics**: Built-in velocity, drag, and collision detection.
- **Procedural Textures**: Custom textures generated via Phaser Graphics with zero external PNG/JPG downloads.
- **Hot Module Reloading**: Save code and see instant updates in browser.

## How to Run:
```bash
./run.sh
```
or
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.
