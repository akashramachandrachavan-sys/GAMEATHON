# ⚡ Template 1: Cyber Survivor (HTML5 Canvas + Web Audio)

A plug-and-play, high-performance 2D arcade survival shooter built with pure HTML5 Canvas and Web Audio API.

## Why this is your #1 weapon for a 4-Hour Gameathon:
- **Instant Play**: Zero build steps, zero node_modules, zero compile errors.
- **Judge-Proof**: Open in any browser (Chrome/Safari/Edge) or double-click `index.html`. You can also deploy to Vercel/Netlify/GitHub Pages in 60 seconds!
- **Procedural Audio**: 100% generated with code. Never fails due to missing `.mp3` files or CORS issues.
- **Built-in "Juice"**: Screen shake, particle effects, floating damage numbers, neon glow, and high score saving.
- **Secret Judge Demo Hotkeys**:
  - `F1`: God Mode (Invincible + Infinite Ammo) — so you NEVER die while presenting to judges!
  - `F2`: Instant Next Wave.
  - `F3`: Add +5000 Score.

## How to Run:
- Double click `index.html` OR run `./run.sh` in this folder.

## How to Adapt to Any Gameathon Theme:
Open `game.js` and look for the `CONFIG` section at the top:
1. **Space Theme**: Change player color to cyan, enemies to red alien ships, bullets to yellow lasers.
2. **Zombie Survival**: Rename Player to "Survivor", enemies to "Zombies", background to dark asphalt `#111`.
3. **Deep Ocean**: Rename Player to "Submarine", enemies to "Sharks" & "Sea Monsters", background to deep navy `#020d1a`.
4. **Cyberpunk Hackathon**: Keep the glowing neon aesthetic!
